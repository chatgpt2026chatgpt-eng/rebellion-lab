# Rebellion Lab / مختبر التمرد

An experimental turn-based tactical simulation prototype, developed as part of a larger strategy game. This repository contains the isolated rebellion lab and its required shared runtime modules, not the complete parent game.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open the URL displayed by Vite. To build: `npm run build`.

## Prototype features

- Turn-based ground operations, terrain and cities
- Rebel and government units, tactical orders and logistics
- Drones, artillery, air operations and defensive systems
- Arabic interface
